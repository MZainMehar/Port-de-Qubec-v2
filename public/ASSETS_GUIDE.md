# Media Assets Guide

## Directory Structure

```
public/
├── fonts/          ← Font files (see fonts/README.md)
├── images/         ← All images
│   └── thumbs/     ← Menu thumbnail images
├── videos/         ← All video files
└── pdfs/           ← PDF documents
```
